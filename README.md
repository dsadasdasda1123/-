# 旅行社示例小程序（可直接导入微信开发者工具）

这是一个可直接导入微信开发者工具的示例项目，覆盖以下核心模块：

- 首页：轮播图、快捷分类、特惠抢购、热门目的地、全局搜索
- 线路详情页：多维展示、动态报价、费用说明、预订须知、在线咨询
- 预订支付：报名信息、优惠券自动匹配、微信支付示例流程、电子合同示例
- 订单维护：状态追踪、电子凭证、图文评价示例

## 使用方式

1. 打开微信开发者工具
2. 选择“导入项目”
3. 项目目录选择当前仓库根目录
4. AppID 可先使用测试号（或替换 `project.config.json` 中 `appid`）
5. 点击编译即可运行

## 说明

- `微信支付`、`电子合同`在此示例中为前端演示流程（模拟成功），生产环境请接入后端下单与签约服务。
- 线上客服使用 `open-type="contact"` 按钮，实际效果取决于小程序后台客服配置。
