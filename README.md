# 羊了个羊风格微信小游戏（可直接导入）

这是一个可直接导入 **微信开发者工具** 的小游戏项目（`compileType: game`），玩法参考羊了个羊：

- 点击未被遮挡的卡牌，放入底部槽位
- 槽位中凑齐 3 张相同卡牌自动消除
- 槽位满 7 张仍未消除则失败
- 清空全部卡牌即过关

## 导入运行

1. 打开微信开发者工具
2. 选择「导入项目」
3. 目录选择当前项目根目录
4. AppID 可使用测试号（项目中默认 `touristappid`）
5. 直接编译运行

## 项目结构

- `project.config.json`：微信开发者工具项目配置（小游戏）
- `game.js`：小游戏入口
- `game.json`：小游戏全局配置
- `src/main.js`：核心玩法 + UI 渲染逻辑

## 视觉说明

UI 使用暖色渐变背景、卡牌阴影、圆角面板、顶部状态栏与结算弹窗，尽量还原羊了个羊的轻松精致观感。
