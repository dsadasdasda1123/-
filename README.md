# 旅游团小程序/网站功能规划

本文档定义旅游团业务的核心模块，覆盖首页导购、线路转化、预订支付、订单维护四大链路，可作为产品、设计与研发对齐基线。

## 2. 核心功能模块清单

### 2.1 首页（品牌入口与导购）

#### 1）轮播图
- 推荐近期热门线路（如暑期亲子游、节假日爆款）。
- 展示促销活动（满减券、早鸟价、秒杀）。
- 企业品牌形象露出（服务保障、资质背书）。
- 支持后台配置跳转目标：线路详情页 / 活动专题页 / 外部 H5。

#### 2）快捷分类
- 提供一级入口：`跟团游`、`私家团`、`周边游`、`定制游`。
- 分类卡片支持图标 + 文案 + 热门标签（如“本周热卖”）。
- 支持后台动态增删分类，按运营优先级排序。

#### 3）特惠抢购
- 限时折扣与爆款线路专区，包含倒计时组件。
- 展示原价、活动价、已售进度，强化紧迫感。
- 活动结束自动下架，避免超卖。

#### 4）热门目的地
- 采用宫格或瀑布流样式展示城市/景点。
- 卡片包含封面图、目的地名称、起价、热度标签。
- 支持按出发地、季节、主题筛选（海岛、亲子、文化等）。

#### 5）全局搜索
- 支持关键词检索线路、目的地、主题词。
- 提供联想词与历史搜索，提升命中效率。
- 结果页支持排序：价格优先、销量优先、好评优先。

---

### 2.2 线路详情页（转化核心）

#### 1）多维展示
- 顶部大图轮播（可扩展视频封面）。
- 线路卖点摘要（适合人群、核心体验、行程天数）。
- 分日程图文说明（D1~Dn），支持景点、餐食、住宿信息。
- 配置“费用包含/不含”“签证/交通说明”“酒店标准”。

#### 2）动态报价
- 日期选择器联动库存与价格。
- 阶梯定价：成人价 / 儿童价 / 单房差。
- 支持“已满团”“余位紧张”等库存状态提示。
- 支持多规格组合实时计算总价。

#### 3）费用说明
- 明确包含项目：交通、酒店、门票、导游、保险等。
- 明确自理项目：个人消费、可选自费项目等。
- 用结构化列表降低争议，便于售后对账。

#### 4）预订须知
- 退改规则（按出发前天数阶梯扣费）。
- 成团要求（最低成团人数、不成团处理方式）。
- 温馨提示（证件、天气、集合时间、健康建议）。

#### 5）在线咨询
- 提供一键唤起微信客服（或企微客服）。
- 同时支持电话咨询、咨询留资。
- 详情页固定悬浮咨询入口，降低跳失。

---

### 2.3 预订与支付流程

#### 1）报名信息
- 支持填写旅客姓名、身份证号、手机号。
- 旅客信息支持保存为常用出行人，复用填写。
- 提交前进行证件格式、手机号合法性校验。

#### 2）优惠券抵扣
- 自动匹配当前线路可用券（满减、立减、折扣券）。
- 展示“最优优惠方案”并支持手动切换。
- 明细透明：原价、优惠、实付金额拆分展示。

#### 3）在线支付
- 接入微信支付（JSAPI / 小程序支付）。
- 支付失败支持重试与订单保留倒计时。
- 支付成功推送消息：订单确认、出行提醒。

#### 4）电子合同（进阶）
- 接入第三方电子合同服务。
- 用户支付后自动生成合同并触发在线签署。
- 支持合同下载、归档和法务审计追溯。

---

### 2.4 订单维护（用户中心）

#### 1）状态追踪
- 订单状态：待付款、待出行、已完成、退款中。
- 支持关键节点进度展示（已下单/已支付/已成团/已出行）。

#### 2）电子凭证
- 查看电子行程单、集合时间地点、紧急联系人。
- 支持二维码核销凭证（线下集合快速验单）。

#### 3）评价系统
- 行程结束后支持图文评价。
- 支持评分维度：导游服务、行程安排、住宿餐食。
- 运营后台可审核评价并沉淀优质内容用于二次转化。

---

## 3. 建议补充的系统能力（便于上线）
- **库存中心**：按团期管理余位，避免超卖。
- **营销中心**：优惠券、拼团、秒杀、老带新活动配置。
- **消息中心**：支付成功、出行前提醒、退改进度通知。
- **风控与合规**：实名信息加密存储、日志审计、隐私协议。
- **后台运营**：线路上架、价格日历、订单导出、退款审核。

## 4. MVP 上线优先级建议
1. 首页导购 + 搜索。
2. 线路详情 + 动态报价。
3. 下单信息 + 微信支付。
4. 用户中心订单查询 + 电子凭证。
5. 优惠券与评价系统作为第二阶段增强。
