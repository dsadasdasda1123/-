# 咩咩三消（微信小游戏）

可直接导入微信开发者工具运行，玩法参考“羊了个羊”：

- 点击上层可见卡片放入底部槽位。
- 槽位中同图案达到 3 张会自动消除并加分。
- 槽位上限 7 格，满了则失败。
- 清空所有卡片即可通关。

## 项目结构

- `game.js`：核心游戏逻辑、触控、绘制与自适应布局
- `game.json`：小游戏全局配置
- `project.config.json`：微信开发者工具项目配置
- `project.private.config.json`：本地私有配置

## 自适应与格子尺寸策略

- 根据机型宽高动态计算 `tileSize`。
- 对格子尺寸做约束：最小 30px，最大 54px，避免格子过大。
- 小屏设备减少列数到 7 列，保持点击精度。

## 导入方式

1. 打开微信开发者工具。
2. 选择“小游戏”项目。
3. 导入目录：当前仓库根目录。
4. 使用测试号（`touristappid`）即可本地预览。
