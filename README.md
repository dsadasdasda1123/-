# uni-app 旅行社示例小程序

本项目已改为 **uni-app 开发**，可在 HBuilderX 直接运行并发行到微信小程序。

## 功能覆盖

- 首页（品牌入口与导购）：轮播图、快捷分类、特惠抢购、热门目的地、全局搜索
- 线路详情页（转化核心）：图集展示、行程说明、动态报价（日期+成人/儿童/房差）
- 预定与支付流程：报名信息录入、优惠券自动抵扣、微信支付示例流程、电子合同模拟签署
- 订单维护（用户中心）：状态追踪、电子凭证、图文评价

## 项目结构（uni-app）

- `main.js`：uni-app 入口
- `App.vue`：全局配置与全局数据
- `pages.json`：页面路由和 tabBar
- `uni.scss`：全局样式
- `pages/*/*.vue`：各业务页面
- `utils/data.js`：示例线路数据

## 使用方式

1. 用 HBuilderX 打开项目根目录
2. 运行到“微信开发者工具”
3. 在微信开发者工具中查看/调试

## 说明

- 该项目中的微信支付、电子合同为演示流程（前端模拟），生产环境需对接真实后端服务。
- 在线咨询按钮使用 `open-type="contact"`，实际效果依赖小程序后台客服配置。
